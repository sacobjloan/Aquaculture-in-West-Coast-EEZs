# Opportunities for Aquaculture in West Coast Economic Zones

### Purpose

Create a function that finds the amount of suitable aquaculture area in each economic zone off the shores of the West Coast. The function takes only 5 inputs, minimum depth for aquaculture, maximum depth for aquaculture, minimum temperature for aquaculture, maximum temperature for aquaculture and species name.
